# 当前限制与明确不支持的范围

MVP 2.0 已支持真实账号、多群组、花名册、邀请码、L1/L2/L3、工作空间同步、显式任务共享和 KairosAdmin。以下范围仍不属于当前版本：

- 不提供群组嵌套、跨群组共享、跨群组任务视图或自定义角色/权限码。
- 不提供公开注册审批流、外部身份提供商、计费、公共云托管或多区域控制面。
- 一个真实账号在同一群组只能有一个有效花名册绑定；群组账号本身不能登录。
- 协作开关开启后不能关闭；开启不会自动共享历史任务，任务必须逐项显式共享。
- Android 只保证前台同步，不提供后台任务、系统通知或提醒调度。
- 客户端支持 JSON 导出，不支持 JSON 导入；删除使用软删除，但当前没有完整回收站页面。
- 链路健康事件只保留当前应用会话最近 50 条，应用重启后可能清空。
- Windows 和 Android 的发布签名、商店打包及自动更新由部署者维护。
- 公网 DNS、TLS 证书、Nginx、负载均衡和防火墙不由 Kairos 管理。
- 客户端允许显式配置局域网 HTTP/WS 并显示警告；公网明文连接不受支持。
- 当前服务端版本为 `0.1.0`，API v2 是 MVP2 的稳定实现但仍保留 v1 兼容路径；后续版本可能增加正式版本化和弃用周期。
- Flutter 全平台构建依赖本机 SDK、平台工具链和签名环境，仓库不包含这些外部依赖。

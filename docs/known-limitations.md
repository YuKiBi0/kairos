# MVP 已知限制

- 仅支持单个自部署实例的个人账号，不提供注册、多用户协作或权限管理 UI。
- Android 只保证前台同步；没有后台任务、系统通知或提醒调度。
- JSON 支持导出，不支持导入；删除使用软删除，但 MVP 不提供完整回收站页面。
- 链路健康事件仅保留当前应用会话最近 50 条，重启后可清空。
- Windows 与 Android 发布签名、商店打包和自动更新不在 MVP 内。
- 公网 DNS、TLS 证书、Nginx 和防火墙由部署者维护。
- 客户端允许显式配置局域网 HTTP/WS 并显示警告；公网使用明文连接不受支持。
- 字体使用平台回退，未在仓库内分发 Noto Serif SC / Noto Sans SC 字体文件。

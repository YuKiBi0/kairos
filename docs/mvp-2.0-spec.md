# Kairos MVP 2.0 产品与技术基线

本文定义 Kairos MVP 2.0 的群组、花名册、邀请码、RBAC、多工作空间同步、协作和 KairosAdmin 范围。

## 产品术语

- 真实账号：服务器范围内唯一、可以登录的自然人账号，一人一号通。
- 个人工作空间：真实账号自动拥有的私人任务空间。
- 群组：共享成员和任务的组织边界，产品界面不使用“租户”。
- 群组账号：群组花名册中的身份条目，可以先于真实账号创建，不保存密码且不能独立登录。
- 绑定：把真实账号与群组账号关联；有效绑定即表示加入群组。

一个真实账号可以加入多个群组；一个群组账号同一时间最多绑定一个真实账号；一个真实账号在同一群组最多绑定一个群组账号。解绑立即撤销访问，但保留花名册、任务归属、绑定历史和审计记录。重新绑定必须二次确认并审计。任务同时记录群组账号归属和实际操作者。

## 邀请码和加入

- 普通邀请码：兑换成功时创建一个群组账号并绑定当前真实账号。
- 花名册认领邀请码：创建时指定未绑定群组账号，成功后绑定当前真实账号；此类邀请码强制只能成功一次。
- 管理员直接绑定：群组管理员可将未绑定群组账号绑定到已有真实账号。

邀请码必须设置过期时间，最长为创建后 30 天；普通邀请码支持有效期内无限次、指定次数、时间与次数同时限制，并可随时撤销。只有绑定事务成功后才消耗次数；同一成功兑换重复提交必须幂等。指定花名册账号时 max_uses 必须为 1。

## RBAC

| 角色 | 等级 | 作用域 |
| --- | --- | --- |
| 独立成员/群组成员 | L1 | 个人空间或指定群组 |
| 群组管理员 | L2 | 指定群组 |
| 超级管理员 | L3 | 全服务器 |

角色可以授予小于或等于操作者等级的角色，但不能突破作用域。L2可以在自己的群组授予 L1/L2，不能授予 L3；L3可以授予 L1/L2/L3。服务器最后一个 L3 不能被停用或降级；群组最后一个 L2 被移除前必须先指定新的 L2，L3 接管群组除外。

## 群组任务和协作

每个任务、标签、项目、清单、困难点、outbox 和同步记录必须属于一个工作空间。客户端切换个人空间和多个群组空间时，筛选、游标、冲突和待上传队列不能混合。群组协作默认关闭；L2/L3 可开启，开启后永久不可关闭，保存不可清空的 collaboration_enabled_at。开启不会自动共享历史任务，只有明确共享的任务允许成员协作。

成员被移除后立即停止该空间同步；未推送操作进入只读恢复区，禁止继续上传。

## KairosAdmin

使用 Go embed.FS 内嵌原生 HTML/CSS/JavaScript，不引入 Node 构建链。唯一入口为大小写敏感的 /KairosAdmin/，不注册 /admin/ 别名或重定向；入口名称不是安全凭据，仍需认证、RBAC、HttpOnly 会话 Cookie、CSRF、CSP、限流和审计。

- L3 管理全服务器真实账号、群组、花名册和角色。
- L2 只能查看和管理自己具有 L2 身份的群组，不能枚举全服务器账号；直接绑定使用精确账号标识查询。
- 停用、解绑、重绑、角色变更、邀请和协作开关均写入审计日志。

## 技术边界

- PostgreSQL 是真实账号、群组、花名册、绑定、角色、邀请码次数和审计的权威数据源。
- Redis 用于缓存、登录/兑换限流、管理会话和多实例 WebSocket Pub/Sub，不得作为权威状态唯一来源。
- 新增 workspaces、groups、group_accounts、group_account_links、group_invites、group_invite_redemptions 和 audit_events。
- 现有任务、归类、outbox、冲突和变更日志增加 workspace_id，唯一键、查询、游标和幂等键都必须包含空间边界。
- 邀请兑换在 PostgreSQL 单事务中锁定邀请和花名册条目，复查撤销、过期、次数和绑定状态后创建绑定与兑换记录并增加次数。
- collaboration_enabled_at 只允许从空变为非空；数据库约束阻止回退。
- v2 同步路径为 /api/v2/workspaces/{workspace_id}/sync/*，服务端每次重新校验访问权；WebSocket 消息包含 workspace_id 但不包含任务正文。
- Redis 不可用时核心个人任务同步不丢数据；邀请码兑换、管理登录、角色变更等敏感入口失败关闭并返回 DEPENDENCY_UNAVAILABLE，健康检查报告 degraded。

## 验收和测试门禁

必须验证空间切换隔离、普通/认领邀请码的 30 天和次数边界、并发兑换唯一性、解绑撤权、L2/L3 作用域、最后管理员保护、不可逆协作、/KairosAdmin/ 与 /admin/ 404、CSRF/CSP、Redis 降级以及 PostgreSQL/Redis 集成测试。CI 不得包含固定密码、令牌或真实环境文件。

# Kairos MVP 2.0 产品与技术基线

本文是当前实现的基线，不再把 MVP2 标记为“开发中”。未列入本文的行为不能作为已支持能力对外承诺。

## 产品术语

- **真实账号**：服务器范围内唯一、可以登录的自然人账号，一人一号通。
- **个人工作空间**：真实账号自动拥有的私人任务空间。
- **群组**：共享成员、花名册和群组任务的边界，产品界面统一使用“群组”一词。
- **群组账号**：群组花名册身份条目，不保存密码、不能独立登录。
- **绑定**：把真实账号与群组账号关联；存在有效绑定即表示加入群组。

一个真实账号可以加入多个群组；一个群组账号同一时间最多绑定一个真实账号；一个真实账号在同一群组最多绑定一个群组账号。解绑立即撤销访问，但保留花名册、任务归属、绑定历史和审计记录。

## 加入群组与邀请码

支持三种路径：

1. 普通邀请码：兑换时创建一个群组账号并绑定当前真实账号。
2. 花名册认领邀请码：创建时指定未绑定群组账号，兑换后绑定当前真实账号；强制只能成功一次。
3. 管理员直接绑定：L2/L3 将未绑定群组账号绑定到指定真实账号，使用精确账号 ID 或账号名（不支持模糊搜索）。

邀请码规则：

- `expires_at` 必填，不能超过创建时间后 30 天。
- `max_uses = null` 表示有效期内不限次数；正整数表示成功兑换上限。
- 时间和次数同时存在时，任一条件触发即失效。
- 指定花名册账号时 `max_uses` 强制为 1，目标必须属于同一群组且未绑定。
- 只有绑定事务成功后才计数；UUID 幂等键保证重复提交不重复计数。
- 邀请码可以主动撤销，撤销、兑换和绑定历史不可通过普通接口删除。
- 每个真实账号每 60 秒最多尝试兑换 10 次，Redis 不可用时失败关闭。

## RBAC

| 角色 | 等级 | 作用域 | 能力 |
| --- | --- | --- | --- |
| 独立成员/群组成员 | L1 | 个人空间或已加入群组 | 访问被授权任务，不管理角色 |
| 群组管理员 | L2 | 自己具有 L2 身份的群组 | 管理花名册、绑定、邀请码和群组策略，可授予 L1/L2 |
| 超级管理员 | L3 | 全服务器 | 管理全部账号、群组、角色和管理后台，可授予 L1/L2/L3 |

角色只能分配给不高于操作者等级的角色；L2 不能分配 L3，也不能跨群组管理。系统阻止停用或降级最后一个 L3；群组保留至少一个 L2，除非由 L3 接管。所有角色变更、停用、绑定、解绑、邀请码和协作开关写入审计日志。

## 工作空间、任务与协作

任务、标签、项目、清单、困难点、outbox、冲突和同步游标都属于一个工作空间。客户端快速切换个人空间和多个群组空间时，任何本地状态都不能混用。

群组协作默认关闭。L2/L3 可以开启，数据库只允许从关闭变为开启，不能回退。开启不会自动共享历史任务；任务所有者或管理员必须逐项设置 `shared_at`。个人工作空间不支持共享。

群组任务记录：

- `group_account_id`：花名册归属；
- `created_by_user_id`：真实账号创建者；
- `last_operated_by_user_id`：最后一次实际操作者。

成员被解绑后，服务端立即拒绝该空间同步；客户端停止上传并进入只读恢复区，可导出不含凭据的恢复包。

群组可以被 L2/L3 停用或由 L3 永久删除。停用保留所有服务端数据但拒绝新建任务，恢复后重新开放；删除按事务清理群组、工作空间、任务、花名册、邀请码、同步记录和审计关联，客户端本地数据库不被远程删除。

## KairosAdmin

后台由 Go `embed.FS` 提供原生 HTML/CSS/JavaScript，不依赖 Node 构建链。唯一入口是大小写敏感的 `/KairosAdmin/`；`/admin/`、`/Admin/` 等路径返回 404。

- L3 可以查看和管理服务器内全部真实账号、群组、花名册、角色和邀请码。
- L2 只能看到自己具有 L2 身份的群组，不能枚举全服务器账号。
- 管理会话使用 HttpOnly、Secure、SameSite Cookie；写请求要求 CSRF token。
- 管理登录、会话和敏感写操作通过 Redis 限流；Redis 不可用时返回 `503 DEPENDENCY_UNAVAILABLE`。

## 数据与依赖

PostgreSQL 是真实账号、工作空间、群组、花名册、绑定、任务、邀请次数、协作开关和审计的权威来源。当前迁移为 `000001` 至 `000007`。

Redis 当前用于限流和 KairosAdmin 管理会话；实时 Hub 为服务进程内实现，不得把 Redis 视为唯一业务事实来源。Redis 不可用时个人任务同步不丢数据，敏感操作失败关闭，健康检查报告降级。

## 不在 MVP2 范围内

群组层级嵌套、自定义角色、细粒度权限码、跨群组共享、外部身份提供商、公开注册审批流、计费、云托管和多区域编排平台均不在当前版本。

# Kairos MVP 2.0 实施计划

1. 规格与工程基线：产品/技术边界、API v2、稳定错误码、迁移和兼容策略。
2. Redis 基础设施：配置、限流、管理会话、Pub/Sub、健康降级、CI 和部署。
3. 群组与 RBAC：真实账号、个人空间、群组、花名册、绑定历史和审计。
4. 邀请码：普通邀请、花名册认领、30 天边界、次数限制、撤销和并发原子兑换。
5. 同步 v2：工作空间隔离的快照、游标、outbox、冲突和 WebSocket 通知。
6. Flutter 多群组：Drift 迁移、空间选择器、离线切换、撤权恢复区和加入流程。
7. 群组协作：不可逆开关、任务可见性、共享编辑和冲突处理。
8. KairosAdmin：原生管理面板、L2/L3 视图、Cookie/CSRF/CSP 和审计。
9. 发布加固：备份、回滚演练、端到端测试、Windows/Android 构建和部署文档。

每个代码 PR 必须通过数据库迁移测试、Go 格式化/vet/单元及 PostgreSQL/Redis 集成测试、Flutter analyze/单元/组件测试和目标平台构建。CI 不得包含固定密码、令牌或真实环境文件。

兼容策略：数据库升级前执行 pg_dump；服务端先支持 v1 个人空间映射和 v2 空间接口；v2 客户端首次快照完成前不删除旧本地数据；Redis 故障不得导致 PostgreSQL 权威数据丢失。
